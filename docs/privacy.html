プライバシーポリシー

Cleanlock は、お客様の個人情報を収集しません。以下はその詳細です。

アプリが集めないもの

  • お名前、メールアドレスなどの個人情報
  • 押したキー、入力した文字、トラックパッドやマウスの操作の内容
  • 画面の内容、使用状況の統計

入力のロックについて

キーボード・トラックパッド・マウスをロックするため、macOS のアクセシビリティの許可を使って、ロックしているあいだの入力を受け取り、そのまま捨てます。入力の内容を記録したり、外部に送ったりはしません。ロックしていないときは何も受け取りません。解除のための長押しは、ボタンが押されているかどうかだけを見ています。

アプリが通信するとき

本アプリが外部と通信するのは、次の 1 つだけです。

  • アップデートの確認 — 1 日 1 回、GitHub（github.com）にある最新版の一覧を読み、新しいバージョンが出ているかを確認します。送信するのは通常の HTTP リクエストのみで、お客様を識別する情報は含みません。設定画面でオフにできます。

ライセンスキーの確認は Mac の中だけで行い、通信はしません。

Mac に保存されるもの

  • 設定 — 起動したときの動作、ロックするもの、画面の色、解除の仕方など。macOS の環境設定（UserDefaults）に保存されます
  • ライセンスキーと試用期間の開始日 — macOS のキーチェーンに保存されます

どれも、お使いの Mac の中にとどまります。

購入したとき

決済は販売代行会社が処理します。カード番号などの決済情報は同社が扱い、当方は受け取りません。同社のプライバシーポリシーが適用されます。当方が知るのは、ライセンスの発行に必要な範囲のみです。

このウェブサイト

本サイトは GitHub Pages でホストされています。アクセスに伴い GitHub がログ（IP アドレス等）を取得します。当方は解析ツールや広告、Cookie を使用していません。
