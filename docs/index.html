できること

メニューバーのアイコンを押して、「キーボードを掃除」か「画面を拭く」を選ぶだけ。終わったら、トラックパッドかマウスのボタンを 3 秒押し続けて解除します。

1キーボード掃除

これまで拭くたびに文字が入り、ショートカットが動き、音量が変わる
Cleanlockキーボード・トラックパッド・マウスをまとめてロック

音量や明るさなどのメディアキーも止めます。キーボードだけ、トラックパッドとマウスだけ、のようにロックするものを選べます。

ロック中は画面を少し暗くして、ロックされていることが分かるようにします（オフにもできます）。

2画面拭きモード

これまで明るい画面では汚れが見えず、触れるたびに何かが反応する
Cleanlockすべてのディスプレイを真っ黒にして、入力もロック

真っ黒の画面では指紋やホコリがよく見えます。筋や拭きムラを見たいときは真っ白にもできます。カーソルも隠します。

つないでいるディスプレイはすべて覆います。拭くときに手が触れても反応しないよう、キーボード・トラックパッド・マウスもすべてロックします。

33 秒長押しで解除、閉じ込められない

ほかの方法解除の仕方を忘れたり、うっかり触れて解除されたり
Cleanlock押し続けたときだけ解除。決めた時間が経てば必ず解除

解除はトラックパッドかマウスのボタンを 3 秒押し続けます（2・3・5 秒から選べます）。押しているあいだは、画面の真ん中に進み具合のリングが出ます。

長押しできないときのため、決めた時間（1・2・5・10 分）が経つと自動で解除します。アクセシビリティの許可が外れたときも、すぐ解除します。

ほかにも

メニューバーからすぐ

ほかの tsubomi のアプリと同じく、メニューバーのパネルが入り口です。アイコンを押して、どちらのモードもすぐ始められます。

開くだけで始まる

設定の「起動したとき」を「キーボードを掃除」か「画面を拭く」にすると、アプリを開くだけで始まります。Dock にアイコンを出しておけば、Dock のアイコンを押すだけで始まります。

ディスプレイが何枚でも

つないでいるディスプレイをすべて覆います。ロック中にディスプレイをつなぎ直しても、そちらも覆います。

この Mac の中だけで

入力はロックのあいだ捨てるだけで、記録も送信もしません。外と通信するのはアップデートの確認だけです。
